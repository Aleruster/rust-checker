# Rust Checker

Клиент-чекер для Rust-сервера: ищет читы и следы их запуска на ПК.

## Что проверяет
- **Файлы читов** — сверка отпечатков PE (секции, экспорт, PDB) на сервере
- **Память RustClient.exe** — поиск подгруженных подозрительных DLL прямо в оперативке
- **JournalTrace** — следы удалённых файлов в журнале NTFS
- **Следы инжекта** (Prefetch: инжектор + чужие DLL в игре)
- **USB-накопители** — история подключений/отключений
- **ExLoader** — .dat моды
- **Последняя активность** (Prefetch), подсветка инжекторов
- **История браузеров** — поиск читов/спуферов/макросов, ИИ-анализ на сервере

## Прозрачность
- Клиент полностью открыт: исходный код на GitHub
- Хэши читов **не публикуются** — только на сервере
- Клиент отправляет только отпечатки (размер, секции, экспорт, PDB) и хэши файлов-кандидатов

## Приватность
- Сервер **не хранит** историю браузера — только анализирует и отдаёт вердикт
- Считается только общее число проверок (без привязки к людям)

## Запуск

### Метод 1: GitHub (рекомендуется)
```powershell
curl -fsSLo "$env:TEMP\Checker.exe" https://github.com/Aleruster/rust-checker/releases/latest/download/Checker.exe
certutil -hashfile "$env:TEMP\Checker.exe" SHA256
& "$env:TEMP\Checker.exe"
```

### Метод 2: Сервер
```cmd
curl -fsSLo "%TEMP%\Checker.exe" http://93.152.223.197:8090/Checker.exe && start "" "%TEMP%\Checker.exe"
```

**Проверка целостности:**
Каждый exe имеет SHA-256 хэш. Вычисли хэш скачанного файла и сравни с хэшем из GitHub Releases.

Если хэши совпадают — файл оригинальный, не вирус.

---

Появится UAC — нажми "Да" (без прав администратора часть данных не читается: MFT, USN журнал, Prefetch, USBSTOR).
