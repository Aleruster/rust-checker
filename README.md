# Rust Checker

Клиент-чекер для Rust-сервера: ищет читы и следы их запуска на ПК.

## Что проверяет
- файлы читов (сверка на сервере по хешам и признакам PE)
- JournalTrace — следы удалённых файлов в журнале NTFS
- следы инжекта (Prefetch: инжектор + чужие DLL в игре)
- USB-накопители (история подключений/отключений)
- ExLoader — .dat моды
- последняя активность (Prefetch), подсветка инжекторов

## Запуск (готовый .exe — в разделе Releases)
Скачать и запустить одной командой в cmd:

```
set "F=%TEMP%\Checker_%RANDOM%.exe" && curl -fsSLo "%F%" https://github.com/Aleruster/rust-checker/releases/latest/download/Checker.exe && start "" "%F%"
```

Выскочит UAC — нажать «Да» (без прав администратора часть данных не читается).

## Исходник
`checker.py` — клиент. База сигнатур читов и сверка живут на сервере, в клиенте их нет.
